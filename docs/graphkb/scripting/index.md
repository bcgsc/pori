# About the Python Adapter

The PORI python adapter is a python package to facilitate interacting with the GraphKB API.

In this section we will focus solely 
The openapi specification of the REST API can be found at [`/api/spec`](https://pori-demo.bcgsc.ca/graphkb-api/api/spec). The client also contains documentation on the background and features of GraphKB (in the about/getting-started section).

This adapter adds functions for common queries as well as for paginating and authenticating
